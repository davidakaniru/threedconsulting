# R6 — Parent Portal refinement

The Parent Portal is organized around the child switcher and the one-to-one tutoring model.

- My children shows active lessons with matched teacher details and agreed schedule.
- Upcoming sessions, meeting links, homework, attendance, and recent activity all read through lesson assignments.
- My enrolments remains the request lifecycle view, showing pending/open/matched state and teacher details once matched.
- The homework card now evaluates overdue state per assignment rather than applying one overdue item's styling to every homework card.
