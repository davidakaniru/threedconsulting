# Parent Experience Polish

The parent academic dashboard now uses a reusable child switcher and remembers the selected learner in browser storage. Switching learners updates the complete academic view.

## Improvements

- reusable learner switcher
- persisted learner selection
- mobile-friendly upcoming-session cards with countdown labels
- homework due and overdue emphasis
- visual attendance progress and status breakdown
- combined activity timeline built from sessions, homework, and attendance
- all data remains scoped by the authenticated parent-to-student relationship

No database migration or new dependency is required.
