# Student Management

Student records are non-authenticated business entities. Admission numbers are generated by PostgreSQL in `STD-YYYY-####` format with a year-specific, concurrency-safe counter.

Student photos are stored in the private `student-photos` bucket. The application stores only the object path and creates one-hour signed URLs on the server for authorized admin views.

Medical data is intentionally excluded. Parent, class, enrollment and document links are deferred to their respective domain modules.
