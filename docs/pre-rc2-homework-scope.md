# Pre-RC2 — Homework removed from scope

Homework/assignments are intentionally disabled for the current release. Active teacher and parent UI, dashboard services, session models, navigation, API/query surfaces, and marketing preview copy no longer depend on homework.

The existing database tables/types and historical migrations are retained so the feature can be reintroduced later without destructive schema changes. Legacy homework URLs are kept only as safe redirects/410 endpoints for merge-based checkpoint compatibility.
