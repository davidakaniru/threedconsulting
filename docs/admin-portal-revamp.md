# Admin Portal Revamp

## Navigation

The admin sidebar is organized around tasks rather than database entities:

- Dashboard
- People: Teachers, Students, Parents
- Academics: Programmes, Cohorts, Enrolments, Sessions
- System: Settings

Teaching assignments remain managed from programme and teacher detail workflows rather than appearing as a standalone navigation destination.

Unimplemented global search and notifications are hidden until functional versions are available.

## Dashboard

The dashboard now combines high-level metrics with operational sections:

- Pending enrolments
- Today's scheduled sessions
- Cohorts at 80% capacity or higher
- Recent audit activity
- Common admin actions

All dashboard items link directly to the relevant management or detail page.
