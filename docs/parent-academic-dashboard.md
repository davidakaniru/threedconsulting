# Parent Academic Dashboard

The parent portal is the learner-facing academic experience; the project has no student portal.

## Child context

Parents can be linked to multiple students. The dashboard provides a child switcher and refreshes all academic sections using the selected learner context.

## Information shown

- Active programmes and cohort memberships
- Upcoming scheduled online sessions with meeting links
- Published homework and per-learner submission state
- Attendance summary and recent history

All server queries are scoped through `student_parents`, so parents only receive information for students linked to their account.
