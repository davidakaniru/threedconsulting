# Teacher My Teaching Page

The teacher portal consolidates read-only programme and cohort information at:

- `/portal/teacher/teaching`

The previous routes redirect to the consolidated page:

- `/portal/teacher/programmes`
- `/portal/teacher/cohorts`

Each programme section displays its cohorts, active membership against capacity, lifecycle status, and the next scheduled session. Teachers can create a new session directly from a cohort card, with that cohort preselected in the session form.
