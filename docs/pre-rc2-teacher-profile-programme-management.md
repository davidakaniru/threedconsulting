# Pre-RC2 — Teacher profile programme management

The Admin Teacher Profile now manages teaching programme eligibility directly inside the existing **Assigned programmes** card.

- Admins can search published programmes and assign one without leaving the teacher profile.
- Already assigned programmes are excluded from the picker.
- Admins can remove an assignment with a destructive confirmation step.
- Removing eligibility does not delete existing lesson assignments or session history; it only removes the programme from the teacher's teaching-assignment eligibility used for new opportunities.
- Legacy teaching-assignment dependencies continue to be protected by the existing server-side removal checks.
