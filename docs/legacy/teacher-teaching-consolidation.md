# Teacher Teaching Consolidation

The teacher portal now uses a single read-only academic overview:

- `/portal/teacher/teaching` — labelled **My teaching**

It groups each assigned programme with its cohorts and displays cohort status, active membership against capacity, and the next scheduled session.

The former routes remain as redirects for backward compatibility:

- `/portal/teacher/programmes`
- `/portal/teacher/cohorts`

Teacher dashboard links and sidebar navigation point to the consolidated route. Cohort cards also provide a **Create session** action that preselects the relevant cohort.
