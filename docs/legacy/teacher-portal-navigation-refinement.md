# Teacher portal navigation refinement

## Navigation

The inactive **Students** entry has been removed from the teacher sidebar. Student work remains cohort-centred through My teaching, Sessions, Attendance, and Homework.

The Attendance item now uses Lucide's `ListChecks` icon to better represent taking a class register.

## My teaching

`/portal/teacher/teaching` is now cohort-first. Every cohort card displays its programme as context, active membership against capacity, lifecycle status, and nearest scheduled session.

Primary actions are exposed directly on each cohort card:

- Create session
- Open attendance
- Create homework

The previous programme-first grouping and duplicated read-only navigation remain removed.

## Teacher dashboard

The My teaching section on the dashboard now presents active cohorts rather than programme assignment summaries. Cohort cards expose student totals, next-session context, and the same primary teaching actions.
