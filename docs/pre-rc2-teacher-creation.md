# Pre-RC2 — Teacher creation refinement

- Teacher employee IDs are generated by the database using the `TCH-0001` style sequence.
- Admins no longer enter an employee ID during teacher creation.
- Admins must assign at least one published programme while creating a teacher and can select multiple programmes.
- Programme eligibility is revalidated server-side before provisioning.
- Teaching assignments are created as part of teacher provisioning; if provisioning fails, the invited auth user is removed so cascading records are not retained.
- Existing teacher editing continues to support the current employee ID field.
